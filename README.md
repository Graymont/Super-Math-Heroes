**ABOUT**

Multiplication is a fundamental mathematics topic that every elementary school 
student must master. However, it is often perceived as difficult and unengaging, 
which can reduce students’ motivation to learn. This study aims to develop a mobile
based educational fighting game using the Unity (2D) game engine as a medium 
for strengthening elementary students’ multiplication skills. The Multimedia 
Development Life Cycle (MDLC) method was applied, consisting of six stages: 
concept, design, material collecting, assembly, testing, and distribution. The game 
was developed in C#. It combines educational content with combat mechanics: 
players must answer multiplication questions correctly to attack their opponent. 
Two players can play on a single mobile device, which encourages interaction. 
Players can also play alone against a Rule-Based Artificial Intelligence. The 
application was evaluated using Black Box Testing and a User Acceptance Test 
(UAT). Black Box Testing showed that all features worked according to the system 
design. The UAT score of 89.45% placed the application in the “Very Feasible” 
category as a medium for strengthening elementary students’ multiplication skills.
